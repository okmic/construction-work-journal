# Журнал работ на строительном объекте
## Описание
Веб-приложение для учёта выполненных работ на строительном объекте. Позволяет вести журнал работ с возможностью добавления, редактирования, удаления записей и фильтрации по дате.

## Стек технологий
### Фронтенд
- **React 18** + **TypeScript** — типизированная разработка UI
- **Vite** — быстрая сборка и разработка
- **TailwindCSS** — утилитарный CSS-фреймворк
- **Redux Toolkit** — управление состоянием
- **Axios** — HTTP-клиент
- **React Hot Toast** — уведомления

### Бэкенд
- **Node.js** + **Fastify** — легковесный HTTP-сервер
  - Fastify выбран вместо NestJS, так как в проекте всего одна сущность (WorkFact) и нет необходимости в тяжёлом фреймворке для микросервиса
- **Mongoose** — ODM для MongoDB
- **MongoDB** — NoSQL база данных
  - Выбрана вместо PostgreSQL из-за небольшого размера проекта и отсутствия сложных связей между таблицами

### DevOps
- **Docker** + **Docker Compose** — контейнеризация
